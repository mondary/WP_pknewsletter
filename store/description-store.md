## Description longue

### FR

**PK Newsletter** est un plugin WordPress pour gérer une newsletter éditoriale quotidienne sans dépendre d'un SaaS : base abonnés, digest HTML, historique d'inscription et envoi SMTP intégré dans une seule interface.

#### ✨ Fonctionnalités clés
- **Dashboard admin dédié** — vues Dashboard, Abonnés, Statistiques et Réglages réunies au même endroit
- **Formulaire d'inscription front** — via le shortcode `[wppk_newsletter_form]`
- **Gestion des abonnés** — ajout manuel, import/export CSV, filtres, pagination et actions unitaires
- **Digest email HTML** — plusieurs mises en forme et thèmes visuels, prévisualisable dans l'admin
- **Envoi de test** — digest de test vers une adresse dédiée avec choix du jour et du template
- **SMTP intégré** — envoi via `wp_mail()` ou configuration SMTP embarquée (ex. Amazon SES)
- **Désinscription tokenisée** — liens de désinscription sécurisés par token
- **Statistiques** — stats d'envoi et courbes d'évolution des abonnés
- **Posts du jour** — contenus publiés et planifiés du jour, avec flag visuel sur les planifiés
- **Bouton flottant (FAB)** — bouton d'inscription optionnel en bas à droite, configurable

### EN

**PK Newsletter** is a WordPress plugin to manage a daily editorial newsletter without relying on a SaaS: subscriber base, HTML digest, subscription history, and built-in SMTP delivery in a single interface.

#### ✨ Key features
- **Dedicated admin dashboard** — Dashboard, Subscribers, Statistics, and Settings views in one place
- **Frontend subscription form** — via the `[wppk_newsletter_form]` shortcode
- **Subscriber management** — manual add, CSV import/export, filters, pagination, and row actions
- **HTML email digest** — multiple layouts and visual themes, previewable in the admin
- **Test sending** — test digest to a dedicated address with day and template selection
- **Built-in SMTP** — send through `wp_mail()` or the embedded SMTP configuration (e.g. Amazon SES)
- **Token-based unsubscribe** — secure tokenized unsubscribe links
- **Statistics** — sending stats and subscriber growth charts
- **Posts of the day** — today's published and scheduled content, with a visual scheduled flag
- **Floating button (FAB)** — optional bottom-right signup button, configurable
